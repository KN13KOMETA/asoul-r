# ASOUL Resurrected

> Please note. This project is currently on rewrite for v2.\
> If you need a working version check [v1](https://github.com/KN13KOMETA/asoul-r/releases/tag/v1.0.0)

Discord bot written in TS with discord.js.

## About bot

### Name

In 2019, I created the ASOUL my first discord bot. But due to the fact that I
did not develop bots for some period, so in 2022 it finally stopped working. But
due to the fact that the code was terrible, I decided that it would be more
correct to write the bot again, but keeping its name, thereby ressurecting it.
The old version is still available [here](https://github.com/ClintFlames/ASOUL)
if you want to check it for some reason.
